# dN/dS Dynamics in Recombining Bacterial Populations

This repository contains the analysis code for the manuscript [*Dynamics of dN/dS
within recombining bacterial populations*, Liu & Good](https://www.biorxiv.org/content/10.1101/2025.09.09.675256).

In short: recombination strongly accelerates the decline of dN/dS with divergence
time, and by separating mutations in clonal versus recombined regions of the
genome we disentangle this effect and infer the underlying strength of selection.
It builds on data and methods from Garud & Good (2019) and Liu & Good (2024).

## Data

- **SNV catalogs of human gut bacteria** — compact SNV catalogs in [this Zenodo
  repository](https://zenodo.org/records/14853785), originally generated by
  [Garud & Good et al. (PLOS Biol 2019)](https://doi.org/10.1371/journal.pbio.3000102).
- **Recombination events inferred by CP-HMM** — in the supplement of
  [Liu & Good (PLOS Biol 2024)](https://doi.org/10.1371/journal.pbio.3002472).
- **Cultured isolate genomes** — high-quality assemblies retrieved from NCBI
  (see `analysis/download_ncbi_isolates.py`) for the isolate-vs-metagenome
  comparison.

External catalogs and reference genomes live outside the repo; paths are
configurable in `dnds_dynamics/config.py` (env-overridable).

## Repository structure

- **`dnds_dynamics/`** — the analysis package: QP (metagenome) and isolate SNV
  access, consumption of CP-HMM recombination events, dN/dS stratification into
  clonal / recombined / full-core regions, and figure-reproduction utilities.
- **`analysis/`** — data-preparation entry points: the NCBI isolate pipeline
  (download → SNV table → CP-HMM recombination → dN/dS) and per-cohort prep.
- **`paper_figures/`** — scripts that produce the manuscript figures (main text
  and supplement). See [`paper_figures/README.md`](paper_figures/README.md) for a
  table mapping each figure to its generating script.
- **`data/`** — vendored figure-input tables.

## Dependencies

Python 3.10; install the Python dependencies with `pip install -r
requirements.txt` (numpy, pandas, scipy, biopython, matplotlib, seaborn,
statsmodels). Recombination detection uses the companion
[`cphmm`](https://github.com/zhiru-liu/close_pair_hmm) package (installed
editable), and isolate SNV tables are built with
[MUMmer 4](https://github.com/mummer4/mummer); see `requirements.txt` for both.
